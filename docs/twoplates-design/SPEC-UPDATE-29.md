# Spec update 29 — Home: Quick start and "Train again?"

Mockups: `mockups/31a-home-done.png`, `31b-home-planned.png`, `31c-quick-start.png`, side by side in `31-home-compare.png`.

## 1. Home states
- **Planned, not done (31b):** hero shows the planned day, "Start Pull day" is the one filled button. Under it a small "OR…" label and three equal glass cards (≥72pt tall, icon above label): Quick start, Pick a day, Surprise me.
- **Done today (31a):** no filled button. "Next up: Pull day · Fri ›" is a tappable link (opens that day's preview). The three cards move up under the heading "Train again?" with the caption "Extra session, mobility or a quick finisher." Cards ≥88pt tall.
- **Nothing planned:** same as 31a with the heading "What do you want to do today?".
- Tiles: each tile has its own background photo (My program and My stats must not share one).
- Sync line shows the real state: "✓ Synced 2 min ago", or the reason when it fails ("iCloud is off", "Waiting for network").

## 2. Quick start (31c), replaces "Build my own"
- Sheet: "What are we hitting?" · caption names the setting in use ("Built from your kit at Gym").
- FOCUS chips: Push, Pull, Legs, Upper, Full body, Arms, Core (single select, palette rule B).
- TIME: 20 / 30 / 45 / 60 min (single select). Defaults: the focus that is least recently trained, and 45 min.
- Preview card updates live: "Pull · 45 min · 6 exercises" plus the list with sets × reps, following the rep-range rules (compounds 5–8, isolation 10–15) and equipment rules.
- Filled button: "Start Pull · 45 min". Text link under it: "Start empty and add as I go".
- Reusable workout building stays in My program; Quick start never saves a template unless the person chooses "Save as a day" at the end of the session.
- Teen members: same sheet; generated sets keep ≥2 reps in reserve.

## 3. Quick start with a buddy (added 13 Nov, mockup 31d)
Hein found Quick start skips straight to the workout with no way to bring a buddy.
- New first row on the Quick start sheet: **TRAINING WITH**: "Just me", one chip per buddy (avatar + name), "+ Invite". Single select; defaults to the buddy remembered for this weekday (same memory as Start session), else Just me.
- With a buddy chosen, a line under the chips: "Sharing one bar · Two stations ▾" (same One bar / Two stations choice as Start session).
- The preview becomes **one plan each**: "Pull · 45 min · one plan each", then a line per person with their own exercises, sets and reps (teen rules apply to a teen's line).
- Button: "Start Pull together · 45 min". It starts the same together session as Start session (invite or join notification, chips with names, "Log on this phone" if the buddy hasn't joined).
- "Start empty and add as I go" keeps the chosen buddy.
