# TwoPlates design specs 21 to 26

Drop location for the TwoPlates iOS design updates, so the Mac build session can fetch them from GitHub instead of relying on iCloud.

- `SPEC-UPDATE-21` to `26`: the specs. Pictures win over text.
- `mockups/`, `html/`: the approved pictures and their HTML.
- `brand/`: the bumper-plate icon (SVG masters, 1024 px PNGs, the icon sheet, gold vs steel hub).

Copy this folder's contents into `twoplates-ios/docs/design/`.
