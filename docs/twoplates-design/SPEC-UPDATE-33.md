# Spec update 33 — Light colour touches (option A, approved 20 Nov)

Mockup: `mockups/35-colour-compare.png` (option A). No layout changes; applied through shared components only.
- Touches use the person's accent colour (Appearance). **Default accent for new users: Gold**; existing users keep theirs; Graphite stays available.
- Primary button: ink fill + 1.5 pt accent outline.
- Action blocks (Quick start, Pick a day, Surprise me and similar): accent icons, accent border at 35 % opacity.
- Status tags ("Next in your program", "Done today", "Rest day"): accent tint background, dark accent text.
- Section labels and the selected tab: the accent's dark text colour.
- Green (#2F7A4C) is reserved for meaning only: done, progress bars, "Your turn", PRs.
- Contrast 4.5:1 for every accent in Light and Dark.
